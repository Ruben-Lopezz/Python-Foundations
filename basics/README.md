# Python Basics

## Overview

This folder contains a collection of introductory Python exercises developed as part of my programming learning journey.

The main objective is to build a solid foundation in Python by practising fundamental programming concepts and applying them through small interactive programs.

## Learning Objectives

Through these exercises, I have practised:

- Variables and basic data types
- User input and output
- Mathematical operations
- Conditional statements (`if`, `elif`, `else`)
- Loops and iteration
- Lists and basic data structures
- Functions
- Random number generation
- Input validation and basic error handling

## Exercises

| File | Description | Main Concepts |
|---|---|---|
| `day01_band_name_generator.py` | Generates a band name using user input. | Variables, strings, input and output |
| `day02_tip_calculator.py` | Calculates a bill including a tip and splits the cost between people. | Numeric data types, arithmetic and formatting |
| `day03_treasure_island.py` | A text-based adventure game where the user makes decisions to find treasure. | Conditional statements and input validation |
| `day04_rock_paper_scissors.py` | A Rock, Paper, Scissors game against the computer. | Conditionals, lists and randomisation |
| `day05_password_generator.py` | Creates a random password for practising lists, loops and string manipulation. | Lists, loops, randomisation and string manipulation |
| `day06_functions.py` | Demonstrates how to define and call a Python function. | Functions and code organisation |
| `day07_hangman.py` | An introductory version of the Hangman word-guessing game. | Loops, conditionals, lists and string manipulation |

## Running the Exercises

Each exercise is an independent Python script.

To run an exercise, use Python 3:

```bash
python day01_band_name_generator.py
```

Replace the filename with the exercise you want to run.

## Development Approach

Each exercise is reviewed and improved where necessary, with an emphasis on:

- Writing readable and understandable code.
- Applying programming concepts correctly.
- Handling basic invalid inputs.
- Keeping programs organised and easy to maintain.

## Future Development

These exercises provide the foundation for more advanced Python programming, including problem-solving, data analysis, scientific computing and engineering-related projects.
